# Transmission Remote GUI

Este repositorio público continúa el proyecto archivado Transmission Remote GUI. Se mantiene principalmente para uso personal, con los cambios y la colaboración disponibles públicamente en [alejohub/transgui](https://github.com/alejohub/transgui).

## Plataforma soportada

La única plataforma soportada oficialmente es Windows 11 x86-64. El toolchain de referencia es Lazarus 4.8 con FPC 3.2.2; HTTPS usa OpenSSL 3.5.x x64 junto al ejecutable.

## Compilar

La build oficial es `build-windows.ps1`, ejecutada con el toolchain nativo de Windows. Las instrucciones, dependencias, artefactos y uso desde WSL2 están en [BUILDING-WINDOWS.md](BUILDING-WINDOWS.md).

Código, incidencias y releases: [alejohub/transgui](https://github.com/alejohub/transgui).
